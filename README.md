# SpendWise 

SpendWise is an AI-powered personal expense management platform designed to help users track, understand, and manage their spending.

It automatically categorizes expenses, detects unusual spending, identifies recurring subscriptions, analyzes spending patterns, predicts future expenses, and provides interactive what-if spending simulations.

## 🚀 Features

- 📊 **Expense Tracking** – Add and manage personal expenses.
- 🤖 **Automatic Categorization** – Uses machine learning to categorize expenses.
- 🚨 **Unusual Spending Detection** – Identifies expenses that are higher than normal.
- 🔄 **Subscription Detection** – Detects recurring payments and subscriptions.
- 📈 **Spending Analysis** – View spending by category and month.
- 🔮 **Spending Prediction** – Predicts future spending based on previous expenses.
- 🧮 **What-If Simulator** – Simulate how an additional expense could affect total spending.
- 💡 **Spending Insights** – Provides useful insights into spending patterns.
